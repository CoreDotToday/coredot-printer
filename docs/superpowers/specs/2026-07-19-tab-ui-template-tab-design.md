# 탭 기반 UI 재구성 + 템플릿 탭 설계 (v2.6.0)

- **날짜**: 2026-07-19
- **배경**: v2.5.0에서 템플릿 조판이 추가됐지만 GUI에는 관련 UI가 없고, 조판이 필요 없는
  키오스크 현장도 많다. 기능을 탭으로 분리해 필요한 현장만 사용하게 한다.
- **승인된 방향**: CTkTabview 탭 구성([서버]/[키오스크]/[템플릿]) + 템플릿 탭에
  목록·파라미터 표시 / 미리보기 / 테스트 인쇄 / 폴더 열기.

## 1. 창 구조 (`app/gui.py` 재구성)

```
상태 표시줄 (공통): ● 서버 상태 · 서버 주소 · v버전(클릭=릴리스 노트)
탭 (CTkTabview): [서버] [키오스크] [템플릿]
제어 버튼 (공통): ▶시작 ■중지 ↻재시작
서버 로그 (공통, expand)
하단 정보줄 (공통): 상태 메시지 · 고객지원 · 버전
```

- **[서버] 탭**: 포트 설정(+저장), 프린터 선택·상태 라벨·새로고침·안내문, Windows 자동 실행,
  외부 접속 허용 — 기존 위젯을 부모만 바꿔 이동 (로직 메서드 무변경)
- **[키오스크] 탭**: URL 입력·저장 목록·저장/삭제, 자동 열기, 확대율 — 동일하게 이동
- **[템플릿] 탭**: 신규 (아래)
- 창 크기 680×800 유지. 탭 전환은 상태를 잃지 않는다(위젯은 전부 생성 유지)
- 포트 입력은 기존 상태줄에서 [서버] 탭으로 이동 (상태줄은 표시 전용으로 단순화)

## 2. [템플릿] 탭

- **템플릿 콤보박스** + 새로고침 버튼: `template.list_templates()` 결과 (백그라운드 스레드 —
  파일 I/O 뿐이라 빠르지만 GUI 관례 유지). 템플릿 없으면 "(템플릿 없음)" 표시
- **파라미터 입력 영역 (동적)**: 템플릿 선택 시 `param_schema()` 기반으로 행 생성 —
  - text/qr → 라벨(필수는 `*` 접미) + `CTkEntry`
  - image → 라벨 + [파일 선택] 버튼 + 선택 경로 라벨 (+ [지우기])
  - 템플릿 변경 시 기존 입력 행 제거 후 재생성
- **[미리보기] 버튼**: 입력값으로 `compose.render()` (백그라운드 스레드) → 임시 PNG 저장 →
  `os.startfile()`로 OS 기본 뷰어 열기. 필수 파라미터 누락 등 `TemplateParamError`는 경고 팝업
- **[테스트 인쇄] 버튼**: `askyesno` 확인 후 같은 입력값으로 렌더 → PNG 임시 파일 →
  `jobs.submit(path, 선택된 프린터)` → 로그에 job_id 기록. 프린터 미선택 시 경고
- **폴더 열기 버튼 3개**: 템플릿/배경/폰트 → `os.startfile(data/<kind>)` (폴더 없으면 생성 후 열기)
- **서버 비경유**: 미리보기·테스트 인쇄는 HTTP API를 거치지 않고 GUI 프로세스에서
  `compose.render()`/`jobs.submit()` 직접 호출 — 서버 미기동 상태에서도 동작 (좌표 조정 루프 개선).
  렌더는 데몬 스레드에서 실행하고 결과는 `root.after(0, ...)`로 반영, 실행 중 버튼 비활성화(재진입 방지)
- 미리보기 dpi는 150 (파일 크기·속도), 테스트 인쇄는 템플릿 dpi 그대로

## 3. 구현 원칙

- `setup_ui()`를 공통 영역 + `_build_server_tab()` / `_build_kiosk_tab()` / `_build_template_tab()`으로 분해
- 기존 위젯 생성 코드는 **부모 컨테이너 변수만 변경**해 이동 — 위젯 속성·바인딩·로직 메서드는 무변경
- 신규 로직은 `_on_template_selected`, `_collect_template_params`, `_template_preview`,
  `_template_test_print`, `_open_data_folder(kind)` 메서드로 추가
- 이미지 파라미터는 파일 경로를 읽어 bytes로 전달 (`compose._load_image_param`이 bytes 처리)

## 4. 검증

- WSL: `py_compile` + 기존 unittest 36개 green (GUI 로직은 win32 의존이라 실행 불가)
- Windows 스모크 추가 항목: 탭 3개 전환 시 각 설정 동작 유지, 템플릿 탭 목록/파라미터 폼 생성,
  서버 **중지 상태**에서 미리보기 동작, 테스트 인쇄 = 미리보기 일치, 폴더 열기 3종,
  기존 스모크 전 항목 회귀 확인
- 버전 2.6.0, CHANGELOG(코드·MD)·smoke-test.md 갱신. API 변경 없음 → 모의 서버 갱신 불필요
