# 템플릿 탭 레이아웃 편집기 설계 (v2.7.0)

- **날짜**: 2026-07-19
- **배경**: 현장에서 요소 위치(box_mm) 조정이 필요하지만 값이 JSON에만 있어 GUI에서 보이지 않는다.
  kogongjang GUI 분석 결과, 핵심 UX는 "좌표 입력 필드 + 값 변경 즉시 갱신되는 창 내장 라이브
  미리보기 + 영역 가이드 박스"였다 (kogongjang gui.py 421–520행). 이를 템플릿 구조에 맞게 일반화한다.
- **승인된 방향**: 필드+라이브 미리보기 수준의 편집기 (드래그 편집기는 계속 스코프 외).

## 1. 템플릿 탭 개편 — 좌(편집)/우(미리보기) 2단

```
[템플릿] 탭
├ 상단 행: 템플릿 콤보 · 새로고침
├ 좌열 (CTkScrollableFrame, 폭 ~370):
│   배경: [콤보 ▾]                       ← data/+번들 backgrounds 목록
│   요소: [콤보 ▾]  (param (type) 표시)
│   위치(mm): X[  ] Y[  ] W[  ] H[  ]
│   (text 요소일 때) 크기(pt)[  ] 폰트[콤보 ▾] 정렬[콤보] 세로[콤보]
│   ☑ 영역 가이드 표시
│   [레이아웃 저장]
│   ── 인쇄 파라미터 (기존 동적 폼: 샘플값 겸용) ──
│   [크게 보기] [테스트 인쇄]  ·  폴더 열기 3버튼
└ 우열: 내장 미리보기 썸네일 (A4 비율, ~240×340) + 상태 라벨
```

- 기존 [미리보기](OS 뷰어) 버튼은 [크게 보기]로 개명 유지. 내장 미리보기가 1차 수단
- 좌열은 스크롤 프레임 — 요소 많은 템플릿·긴 파라미터 폼에도 높이 제약 없음

## 2. 라이브 미리보기

- 편집 필드·파라미터 입력의 tk 변수에 `trace_add` → **300ms 디바운스** 후 재렌더
  (kogongjang 패턴, `after_cancel` 재예약)
- 렌더: **실제 `compose.render()`** 를 dpi 72로 호출 (백그라운드 데몬 스레드,
  세대 토큰으로 낡은 렌더 결과 폐기 — 서버 폴링과 동일 패턴) → `CTkImage`로 우열에 표시
- 샘플 파라미터: 기존 파라미터 입력값 사용, 필수 text 파라미터가 비어 있으면 `"홍길동"` 대체
  (미리보기 전용 — 인쇄에는 대체 없음)
- 입력값이 일시적으로 잘못된 동안(빈 칸, 숫자 아님): 직전 미리보기 유지 + 상태 라벨에
  주황 경고 (kogongjang과 동일 — 라벨 이미지 비우지 않음)
- **가이드 박스**: 체크 시 선택 요소의 box를 렌더 결과 위에 빨간 실선으로 오버레이
  (GUI에서 PIL 사본에 그림 — compose.py는 순수하게 유지)

## 3. 편집 모델·저장

- 템플릿 선택 시 정규화 dict의 **작업 사본**을 만들어 편집 필드와 바인딩
- 편집 대상 필드: 모든 요소 공통 `box_mm`(X/Y/W/H, mm 소수 허용), text 요소는
  `size_pt`·`font`·`align`·`valign` 추가. (색상·fit·border 등은 JSON 직접 편집 — 스코프 외)
- 배경 콤보: `background` 교체 (data/backgrounds + 번들 목록, "(없음)" 선택 가능)
- **[레이아웃 저장]**: 작업 사본을 검증(`validate_template`) 후
  `data/templates/<id>.json`에 **원자적 저장**(tmp + `os.replace`) → 저장 즉시 API에도 반영.
  번들 전용 템플릿(data/에 파일 없음)도 저장 시 data/에 생성됨 (기존 우선순위 규칙과 일치)
- 미저장 변경이 있는 채로 템플릿 콤보 변경/새로고침 시 `askyesno` 확인
- 저장 성공 시 로그 기록 + `_templates` 갱신

## 4. app/template.py 확장 (PIL 무관 — WSL 테스트 대상)

- `load_template(name)`이 반환 dict에 `"id": <파일명 스템>` 추가
  (`name` 필드와 파일명이 다를 수 있으므로 저장 대상 식별에 필요; `validate_template`은 무관)
- `list_assets(kind)` 신설: data/<kind> + 번들 <kind>의 파일명 목록 (중복 제거, 정렬) —
  배경·폰트 콤보 채우기용
- `save_template(template_id, data)` 신설: `validate_template` 통과 후
  `data/templates/<id>.json`에 원자적 저장 (`ensure_ascii=False, indent=2`).
  `id`는 `resolve_asset`과 동일한 파일명 가드 적용
- 저장 시 정규화 dict에서 `id` 키는 JSON에 기록하지 않음

## 5. 검증

- WSL unittest: `id` 부여, `list_assets` (data 우선·중복 제거), `save_template`
  (원자성은 결과 파일 검증, 잘못된 데이터 거부, id 가드) — 기존 36개 + 신규
- Windows 스모크 추가: 요소 선택→X/Y 수정→미리보기 300ms 내 갱신, 가이드 박스 표시,
  잘못된 입력 중 직전 미리보기 유지+경고, [레이아웃 저장] 후
  `GET /preview-template`(API)에도 반영, 미저장 변경 경고, 감사장에서 사진·이름·(QR 추가 시) 각각 조정
- 버전 2.7.0. API 무변경 → 모의 서버 갱신 불필요
